# Product Overview

SchemaForm is a type-safe React form library that automatically generates forms from Zod schemas. The library provides:

- **Schema-driven forms**: Generate React forms directly from Zod validation schemas
- **Type safety**: Full TypeScript support with compile-time type checking
- **UI adapter pattern**: Support for multiple UI libraries (Material-UI, custom adapters)
- **React Hook Form integration**: Built on react-hook-form for performance and validation
- **Monorepo architecture**: Core library with documentation and example applications

The project follows a modular design where the core library (`@schemaform/core`) provides the foundation, while UI adapters enable integration with different design systems. The documentation app demonstrates usage patterns and provides interactive examples.
